# Security

- **Cross-User Protection:** The `GET /api/v1/intelligence/complaints/{id}` route verifies explicitly that the active JWT session owns the targeted complaint resource before projecting relationship intelligence outward.
- **Embedding Leakage:** The core vectors `[0.12, 0.45, ...]` generated by the transformer are explicitly decoupled from all Pydantic projection models, securing proprietary coordinate mapping parameters away from malicious reverse-engineering.
